## c) Porttiskannaa

Suoritin porttiskannauksen komennolla nmap -T4 -A 127.0.0.1. -T4 nopeuttaa skannausta ja -A tekee tarkemman tunnistuksen. 127.0.0.1 tarkoittaa omaa Kali-konetta.

Alkuperäinen tehtävänannossa annettu komento oli nmap -T4 -A localhost, mutta Kali ei onnistunut ratkaisemaan localhost-osoitetta Nmapille.

Nmap skannasi 1000 yleisintä TCP-porttia. Kaikki 1000 porttia olivat suljettuja, eikä avoimia portteja löytynyt.

## e) Hackthebox machine: Cap

1. Kohteen kartoitus
Aloitettiin nmap-skannauksella: nmap -T4 -A 10.129.109.49

Löytyi kolme avointa TCP-porttia
21 -> FTP
22 -> SSH
80 -> HTTP

2. Web-sovelluksen tutkiminen
avattiin portissa 80 toimiva verkkosivu, josta löytyi Security Snapshot toiminto.

Tutkimalla huomattiin, että muiden numeroiden käyttäminen url:n id numerona mahdollisti muiden käyttäjien skannaustulosten tarkastelun.

3. PCAP tiedoston löytäminen
Havaittiin, että arkaluontoista tietoa sisältävä PCAP löytyi /data/0 url:sta

Wiresharkissa käytettiin suodatinta "ftp", joka paljasti nathanin käyttäjä tunnuksen ja salasanan.

4. SSH-yhteys nathaniin
Koska sama salasana toimi myös SSH-palvelussa, yhdistettiin nathanin käyttäjänä: ssh nathan@10.129.109.49.

Sieltä sitten löytyi user.text eli tiedosto josta löytyi käyttäjäflag.

5. Privilege Escalation
Seuraavaksi tutkittiin linuxin capabilities-asetuksia: getcap -r / 2>/dev/null

Joka tuotti: /usr/bin/python3.8 = cap_setuid,cap_net_bind_service+eip

cap_setuid mahdollisti python prosessin käyttäjä ID:n vaihtamisen root-käyttäjän UID:ksi 0.

6. Rootflag
Siirryttiin rootin kotihakemistoon, josta löytyi root.text eli rootflag.
